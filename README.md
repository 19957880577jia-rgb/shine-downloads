# 拾光

拾起所见，留作灵感。

拾光是一款在本机运行的视觉素材发现、采集、批阅与 Eagle 整理工具。

## 下载安装

**[下载最新版完整安装包](https://github.com/19957880577jia-rgb/shine-downloads/releases/latest)**

当前支持 macOS 12 或以上的 Apple Silicon（M1 / M2 / M3 / M4 等）Mac。

1. 在版本页面下载 `shine-Full-Installer-macOS-arm64-v版本号.zip`。
2. 完整解压后运行「开始安装.command」。
3. 打开「拾光」，按应用引导完成小红书登录；Eagle 连接可选。

安装包内置本地运行组件，不包含使用者的登录状态、Cookie、个人配置或私人素材。素材和个人配置保存在使用者自己的电脑。

## 版本与更新

本仓库只发布安装包、版本说明和下载指南，不公开完整项目源码。

从 v0.3.61 起，应用会通过本公开仓库检查并下载更新，无需 GitHub 登录。v0.3.60 用户请手动下载并安装一次新版，之后即可使用新的更新渠道。

安装包包含运行所需的程序组件；不公开 GitHub 源码并不意味着安装包中的运行代码无法被提取。
